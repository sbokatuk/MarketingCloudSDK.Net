## What's changed

A re-pin release. No managed code in this repository changed, the API is what `11.0.2.2` shipped,
and the native line is unchanged — MarketingCloudSDK **11.0.2** on iOS, marketingcloudsdk
**11.0.1** on Android, SFMCSDK **4.0.1** underneath. Both pins that had fallen behind move:

| | was | now |
| --- | --- | --- |
| `MarketingCloudSDK.Net.iOS` | `11.0.2.2` | `11.0.2.3` |
| `SFMCSDK.Net` | `4.0.1.1` | `4.0.1.2` |

`MarketingCloudSDK.Net.Android` stays at `11.0.1.2`, which is current.

### What the new pins bring

`SFMCSDK.Net 4.0.1.2` is a façade-only revision over the same bindings. It adds **`IsSupported`
and `IsInitialized`** to `ISfmcSdkClient` — members that answer on every target framework instead
of throwing, so shared code has something to branch on — and **`NullSfmcSdkClient`**, the no-op
implementation for MAUI heads with no SDK and for tests. It also corrects the MAUI
target-framework guidance and states, in both directions, that an app using MobilePush needs only
*this* package and must never call the core façade's `InitializeAsync`, because the MobilePush
façade already configures the core with its module attached.

`MarketingCloudSDK.Net.iOS 11.0.2.3` is a test-and-documentation revision whose projected API is
byte-for-byte `11.0.2.2`'s. It repairs three checks that could not fail — an AppGroupSDK probe
looking for a class name that does not exist, an initialization smoke test whose assertion matched
an inactive stub, and a README-version check blind to the core pin — and fixes a README quick-start
that did not compile. Full detail in [its own
notes](https://github.com/sbokatuk/MarketingCloudSDK.Net.iOS/blob/HEAD/docs/release-notes/11.0.2.3.md).

### Upgrading from 11.0.2.2

```diff
-<PackageReference Include="MarketingCloudSDK.Net" Version="11.0.2.2" />
+<PackageReference Include="MarketingCloudSDK.Net" Version="11.0.2.3" />
```

Nothing to change for callers of `IMarketingCloudClient`, which is unchanged.

One thing to know if you reach past this façade to the core: **a hand-written fake implementing
`ISfmcSdkClient` must now add `IsSupported` and `IsInitialized`**, or switch to
`NullSfmcSdkClient`. `SFMCSDK.Net` is pinned exactly, so this arrives with the upgrade rather than
when you choose it. Fakes of `IMarketingCloudClient` are unaffected.
